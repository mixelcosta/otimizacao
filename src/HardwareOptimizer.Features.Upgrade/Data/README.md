# hardware_catalog.json

Catálogo estático hand-curated de compatibilidade de peças (CPU, GPU, placa-mãe), embarcado como `EmbeddedResource`. Consumido por `ValidadorCompatibilidade`/`GeradorSugestoes`.

- **Origem:** curadoria manual pontual durante o protótipo inicial de `Features.Upgrade`.
- **Cobertura:** ~15 peças — não é exaustivo.
- **Atualização:** sem processo automatizado; edição manual do JSON.

Ver `docs/planning-artifacts/architecture/architecture-otimizacao-2026-08-21/ARCHITECTURE-SPINE.md` (Deferred — "Curadoria/crescimento do catálogo estático de compatibilidade") para o plano de evolução.
